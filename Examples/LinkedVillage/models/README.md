# Village models

Three text documents. [`scene.3md`](../scene.3md) names them from its
`3md-files` ledger. The village note is [one folder up](../README.md).

| File | Who names it | What is inside |
|------|----------------|----------------|
| [house.3md](house.3md) | Village glyphs `1` and `4` | One plane. An ASCII house. |
| [tree.3md](tree.3md) | Village glyph `2`, and the tower glyph `T` | One plane. An ASCII tree. |
| [tower.3md](tower.3md) | Village glyph `3` | One plane. Its ledger maps `T` to `tree.3md` in this folder. |

Each file uses newlines and ends with one. The pictures sit inside fences.
The library does not open these paths. A host supplies the bytes. This folder
is not a Sculpt schema.

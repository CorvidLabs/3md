# Requirements

Optional plane identities use preserved attributes and do not change raw parsing. Immutable typed patches validate every operation and final value, check a revision precondition, bound work and propagate cancellation without partial publication. Structured diagnostics describe invalid identities, target/coordinate conflicts and stale edits. Release documentation identifies supported formats and readers, migration boundaries and later milestones.

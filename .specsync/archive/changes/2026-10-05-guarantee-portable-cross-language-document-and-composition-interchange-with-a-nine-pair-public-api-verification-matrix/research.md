# Research

The existing extension manifest includes two principal wire fixtures, additional Unicode cases and 45 finite-number formatting vectors, but no permanent nine-pair driver. Swift Foundation trims a broader horizontal whitespace set than the ports. Swift dictionary keys use Unicode canonical equivalence; the ports need first-spelling/last-value reconstruction for source input. TypeScript link extraction imposes undocumented target/label limits. Legacy writer number/key spelling differs from the separately canonical storage writer. Preserve legacy grammar and valid vectors while repairing semantic incompatibilities; exact-byte parity is required for the canonical writers rather than every legacy spelling.

Direct Rust BTreeMap values cannot recover insertion order for equivalent Unicode duplicate keys and explicitly reject ambiguous values. This is distinguished from portable source decoding. Swift-only renderers, optional Apple LZFSE and idiomatic coding types are not claimed as portable file features. JSON-line adapters remain development-only. Prior numeric sampling is useful evidence but not exhaustive proof.

# Research

Read-only workers studied the current Swift contracts and existing port serializers. Known differences include decimal formatting, TypeScript unpaired surrogate replacement and Rust serde_json duplicate-key loss. New storage validation and a strict scanner address those differences without changing legacy parsing. No third-party runtime library is required. Indexed storage, material/timing profiles and a renderer integration remain outside this preparation.

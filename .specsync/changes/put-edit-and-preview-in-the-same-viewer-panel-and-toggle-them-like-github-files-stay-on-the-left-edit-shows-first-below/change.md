# Put Edit and Preview in the same viewer panel and toggle them like GitHub. Files stay on the left. Edit shows first. Below 900px, Files and the document take turns, and the document panel still switches Edit and Preview.

## Intent

Put Edit and Preview in the same viewer panel and toggle them like GitHub. Files stay on the left. Edit shows first. Below 900px, Files and the document take turns, and the document panel still switches Edit and Preview.

## Affected Canonical Specs

- `ThreeMDViewer`

## Acceptance Criteria

- On a wide window, files stay on the left while Edit and Preview switch in one panel. Edit shows first and hides the preview. Preview shows the live plane view and hides the editor. Below 900px, Files and the document take turns, and the document still switches Edit and Preview. GitHub open, search, pack, and kind 2 stay. The element stays a text renderer.

## No-spec Rationale

Not applicable

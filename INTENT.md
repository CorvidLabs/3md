# 3md

3md is Markdown with a Z axis. The text file is the document you edit. Binary stores those same frames as fields. Named documents can be reused inside one file, or named from local files whose bytes you supply. Swift, TypeScript, and Rust agree on that contract. GDScript is the Godot 4.7 addon, with a smaller editing surface. Sculpt.3md is the Mac app in this repository, and its own wants live in apps/sculpt/hi.

The title above is the product, not this worktree's directory name.

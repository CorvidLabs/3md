# Sculpture

## Intent

I want to sculpt in the main window, orbit what I have made, name it, and undo an edit.

I want that work to stay on this Mac, and I want a file that is not this sculpture to be refused.

I want easier editing by sight, editor actions I can find from the keyboard, and a local agent that can apply the same document rules to a file I choose.

## Criteria

- **SCULPTURE-1**  I can open the main window and orbit a small hollow ASCII orb before I change anything.
- **SCULPTURE-4**  I can choose a cell from the orbit preview.
- **SCULPTURE-5**  I can undo and redo those edits.
- **SCULPTURE-6**  I can name the sculpture with a short printable title.
- **SCULPTURE-9**  A file that is not this sculpture, or that uses a schema the app does not support, is refused and leaves the sculpture I am editing in place.
- **SCULPTURE-10**  The camera lasts only for this session. The app does not send the sculpture off this Mac, and it reads or writes a file only when I choose that file.
- **SCULPTURE-12**  I can edit the sculpture more easily by sight in the main window.
- **SCULPTURE-19**  I can find and run editor actions from a keyboard command palette, and controls have clear accessible names.
- **SCULPTURE-20**  A local agent can inspect a chosen 3md file and apply a validated batch of explicit edits to a new file, using the same document rules as the editor.

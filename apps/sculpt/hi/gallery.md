# Gallery

## Intent

I want curated examples and spatial maps, including people, animals, a castle, worlds, a solar system, and a block landscape, each findable as a 3md file, a PNG, a video, a GIF, and an OBJ mesh.

I want every example, including compositions and worlds, in one gallery, and a math-generated size ladder that shows its size and opens with loading progress I can cancel.

## Criteria

- **GALLERY-11**  I can open curated examples and spatial maps, each a deterministic sculpture inside the existing ascii-sculpture-1 bounds.
- **GALLERY-17**  I can find every example in the gallery on GitHub as a 3md file, a PNG, a video, a GIF, and an OBJ mesh.
- **GALLERY-24**  I can open detailed examples of a human, animals, a castle, and worlds, and find their editable 3md files and all five export formats in the repository.
- **GALLERY-26**  I can open a large solar-system sculpture with the Sun, eight distinct planets, moons, Saturn's rings and an asteroid belt, edit it in Cubes or ASCII, and find it in all five repository formats.
- **GALLERY-32**  I can open and edit an original Minecraft-style block landscape in Sculpt.3md, with reusable map chunks and a sparse-world version, and find its source files, preview and existing export formats in the repository.
- **GALLERY-41**  I can browse every example in one gallery, including compositions and worlds, and open a math-generated size ladder: voxel models at 16, 32, 64, 128 and 256 cells per axis. Each shows its size and opens with visible loading progress that I can cancel. Existing examples, files and limits are unchanged.

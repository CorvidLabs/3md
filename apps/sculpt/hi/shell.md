# Window

## Intent

I want one Sculpt.3md window, Settings, and a menu bar, and I want Show Sculpt.3md to bring back that same window.

## Criteria

- **SHELL-1**  I can use one main Sculpt.3md window.
- **SHELL-2**  I can open Settings.
- **SHELL-3**  The menu bar offers Show Sculpt.3md, Settings, and Quit Sculpt.3md.
- **SHELL-4**  Closing the window and choosing Show Sculpt.3md brings back that same window.
- **SHELL-5**  I can set appearance to match the system, light, or dark, and that choice is the only preference the app stores for me.

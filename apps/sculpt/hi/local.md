# On this Mac

## Intent

I want ordinary use of this app to stay on my Mac.

## Criteria

- **LOCAL-1**  I can use the app without an account, a wallet, or a network connection.
- **LOCAL-2**  The app reads or writes a file only when I choose it, and does not start another program as part of ordinary use.

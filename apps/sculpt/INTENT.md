# rook

Sculpt.3md is the product name, developed in the `CorvidLabs/sculpt-3md` repository. Its Swift modules, executable, and bundle identifier remain Rook. It is a native Mac app with one window, Settings, and a menu bar. The main window edits 3md volumes in translucent cubes, ASCII, and spatial slices. Curated examples include people, animals, castles, worlds, and a large solar system. Editing supports 256 cells along each axis, with zoom and scrolling for individual cells. A five-format gallery carries 3md, PNG, GIF, MP4, and OBJ files. Exact verification and feature-branch publication evidence are recorded separately in the sculpture documents.

The window title and menu bar extra are Sculpt.3md. The menu bar offers Show Sculpt.3md, Settings, and Quit Sculpt.3md. Closing the window and choosing Show Sculpt.3md brings back that same window. Settings stores appearance only: system, light, or dark. Sculpture files are chosen by the person. The camera is not stored. The executable remains Rook, and the bundle identifier remains `labs.corvid.rook`.

Ordinary use stays on this Mac. It does not need an account, a wallet, or a network. On 2026-10-07 the retired launcher hi files were deleted. Git history keeps that text. Those features stay out of the product. Sculpture criteria live in one file per concern: sculpture, slice, cubes, export, gallery, render, composition, and world. A criterion keeps its number. SCULPTURE-30 is COMPOSITION-30.

Shared voxel models can be edited inside their composition or sparse world through an explicit Apply/Cancel session. Applying updates every reference, preserves the graph and creates one complete Undo step. One world voxel placement can be made unique.

EXPORT-35 adds explicit portable text/uncompressed-binary copies and content-detected reopening through ThreeMD 2.0.0. Shared model identities, revisions and transactional patches guard native and explicit-file agent edits. Existing Sculpt formats and default saves remain, with clear portable capacity errors and no automatic user-file migration. Sculpt pins the published ThreeMD 2.0.0 release exactly. The first public release adopts ThreeMD 2.1 after that version is tagged. Until then the pin stays 2.0.0, and no release build is cut. See [distribution](docs/distribution.md).

COMPOSITION-38 adds direct selected-file/folder insertion of supported voxel and tile-map graphs, automatically binding and placing them with one Undo and preserved portable annotations. Core linked-file authoring is separately prepared; native Insert embeds supported files without watchers, processes, network access or a dependency migration.

COMPOSITION-39 makes insertion discoverable from the File menu, a shortcut and the command palette, keeps menu Undo on the open sheet, refuses saves that could not reopen, falls back to native storage only when no portable data would be lost, and names the file or the limit in refusals. Explicit-file RookTool commands apply the same insertion checks for local agents without controlling the app.

## Features

WORLD-36 measures a literal physically initialized 1024-cubed one-byte development buffer and supported reusable worlds with that address domain. Storage, loading, memory and synchronized offscreen Metal results are recorded as a case study. Individual editable models remain 256 cells per axis, and the explicit stress probe does not run during ordinary use or routine CI.

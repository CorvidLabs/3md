# Trust boundaries

| Boundary | What crosses it | Who enforces it |
| --- | --- | --- |
| Person to window | Show Sculpt.3md, Settings, Quit, edits | The app keeps one main window |
| Settings | `rook.appearance` | Unknown values become system. No other key is the product store |
| Sculpture file | A sculpture, composition, world, or export the person chooses | User-selected read-write only. Unsupported schemas are refused and are not converted |
| Camera | Session pose | Not written to the file or to settings |
| Network | Nothing | No network client in the product, and no network entitlement |
| Development tools | Pinned `hi`, `specsync`, `swift`, and `codesign` | RookTooling only. The app does not import it |

Logs are not a product feature. The appearance value may be included in a backup of the app's defaults.

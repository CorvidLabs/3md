# Cubes and larger worlds verification

This iteration implements SCULPTURE-21 through SCULPTURE-25 under Leif's direct request for transparent cube painting, complex humans, animals, castles and worlds, and parallel agents. These are Codex execution observations, not independent human review or SpecSync lifecycle approval. Historical draft and halted changes remain unchanged.

## Implementation and artifacts

The same `ascii-sculpture-1` document supports Cubes and ASCII presentation. Each axis is bounded at 64; encoded input is bounded at 1 MiB. Camera, style, opacity and interaction mode stay outside the saved document. The original twelve examples remain first in the catalog; eight new 64-cubed entries add a cartographer, dragon, fox, whale, castle, sky village, canyon and harbor. All twenty have 3md, PNG, GIF, MP4 and OBJ artifacts in `Examples/`, with manifest metadata and direct gallery links. Original cached artifacts were preserved.

Cube geometry uses visible exterior faces, alpha fills, edges and selected-slice ghost cells. A native canvas-local NSView receives pointer events over the Metal bitmap view. It does not use a global monitor. Draw adds an empty face neighbor or an empty selected-slice cell, Erase removes the clicked cell, and Fill changes a four-connected material region on one slice. Each drag freezes its initial hit geometry and is one undo step. Camera drags remain separate from Paint mode. Preview work is cancellable and leaves the main actor; OBJ preflight rejects more than 250,000 exterior faces before mesh allocation.

Removing that parent modifier restored distinct `editor.slice.zoom.fit`, `.2x` and `.4x` identifiers in the rebuilt running app. The correction's final seven-step lane passed in 59.944 seconds: 143 tests in seven suites after 36.651 seconds, the 29-test harness after 0.999 seconds, hi at 32 active criteria and 53 retired, five strict specs with zero warnings and 40/40 files and 6733/6733 lines, source boundaries and release fixtures. Earlier attempts remain intact. Only documentation changed after this lane. The corrected bundle was opened and left on the unchanged 17110-cell castle in Cubes.

The packaged app displayed the cube orb in its real Metal canvas. Face drawing changed 608 occupied cells to 609; Cmd-Z restored 608. A continuous drag changed 608 to 611; a single Cmd-Z restored all three added cubes. Erase changed 608 to 607 and Undo restored it. With Paint off, a pointer drag changed camera yaw from -0.6 to 0.36 and pitch from 0.35 to 0.59 while leaving the document clean. Mouse input retained the canvas keyboard responder.

Gallery search loaded the Wandering cartographer (8474 cells), Clockwork dragon (11964), Citadel of arches (17110) and Sky island village (9529). All appeared visibly in the live canvas with their geometry intact. Switching the human to ASCII preserved 8474 cells. The castle's 64-by-64 Slice editor at 2× zoom accepted Right, Down and Space: selection moved to 2,2 and occupancy increased to 17111; Undo restored 17110. A new empty 64-cubed volume opened with Paint enabled and a visible slice grid; clicking it added the first cube at 34,31,33. Undo returned to zero.

Native file panels saved the castle as 3md, PNG, GIF, MP4 and OBJ into a temporary user-selected folder. The 3md reopened in the app with its title, dimensions and 17110 cells intact, and its bytes exactly matched the canonical example. The PNG decoded at 576×648; GIF decoded forty frames at that size; MP4 reported four seconds, ten frames per second and no audio tracks; OBJ contained 29858 vertices and 30830 faces. Byte counts and inspected metadata are in [native-export-receipt.json](native-export-receipt.json). Those temporary exports are not duplicate published gallery files. Automated tests separately decode changing animation frames, verify mesh surfaces/winding, and exercise cancellation cleanup and output refusal.

The app was left open on Citadel of arches in Cubes, with Paint off and no unsaved changes. The user's earlier 816-cell Woven torus backup remains outside the repository, unchanged. Packaging uses an ad-hoc local signature and preserves the sandbox and user-selected read/write entitlement.

## Publication and limits

Private feature-branch publication is authorized. This iteration is published as [PR29](https://github.com/CorvidLabs/rook/pull/29) on `leif/voxel-sculpting-worlds`, based on merged main `91ae025d062ac42a6b0729b4a599d774f4f6c1da`. GitHub CI and PR status are separate evidence recorded by that PR at its exact current head. This work does not record lifecycle approval, review or finalization, push main, release, or deploy.

Translucency is painter-ordered exterior cube faces, rather than volumetric ray tracing. The bounded 64-cell volume is deliberate; OBJ refuses pathological surface counts. The existing file interface edits explicitly supplied files and does not remotely control the running app. The product remains Swift, offline, and without network access, processes or bundled example resources.

# SculptSources

## Purpose

This is the monorepo path index for Sculpt.3md implementation sources.
Atlas at the repository root matches spec file paths exactly.
The Rook specs list those same files from `apps/sculpt`, which is where `specsync check` for the app runs.
This index repeats the paths from the repository root so the public spec coverage count includes the app.
It is not a second behavioral contract and it is not a ThreeMD format spec.
The normative specs remain `apps/sculpt/specs/`.
Intent for the app remains `apps/sculpt/hi/`.
Compact `.3mdb` stays the app's save. It is not an upstream ThreeMD binary standard.

## Public API

No symbols are declared here. Public behavior is specified in the Rook module specs.

## Invariants

- Every implementation source under `apps/sculpt/Sources` is listed here and in exactly one Rook spec, except this index, which lists all of them for the repository atlas.
- Tests, docs, examples, and `Package.swift` stay out of this index. The repository `.atlasignore` keeps them out of the coverage denominator, as it already does for the format library.

## Behavioral Examples

Behavioral examples live in the Rook specs. This index does not add behavior.

## Error Cases

This index does not define errors.

## Dependencies

Depends on the Rook specs for behavior and on ThreeMD at the repository root for the format library. No package dependency is added.

## Change Log

- Version 1: repository-root paths for the nested Sculpt.3md sources, so spec coverage can see the app.

# RookApp

## Purpose

The native Mac shell: one window, Settings, a menu bar, and a cube or ASCII sculpture editor in that window. The visible working name is Sculpt.3md. The executable and bundle identifier stay Rook. Intent: SHELL-1, SHELL-2, SHELL-3, SHELL-4, SHELL-5, LOCAL-1, LOCAL-2, SCULPTURE-1, SLICE-2, SLICE-3, SCULPTURE-4, SCULPTURE-5, SCULPTURE-6, EXPORT-7, EXPORT-8, SCULPTURE-9, SCULPTURE-10, GALLERY-11, SCULPTURE-12, EXPORT-13, EXPORT-14, EXPORT-15, EXPORT-16, GALLERY-17, SLICE-18, SCULPTURE-19, SCULPTURE-20, CUBES-21, CUBES-22, CUBES-23, GALLERY-24, RENDER-25, GALLERY-26, CUBES-27.

## Public API

EXPORT-35 adds explicit File-menu portable text and uncompressed-binary copy exports for the current voxel scene or reference editor. Open recognizes portable contents and routes the complete scene into the existing editor. Preparation is immutable and cancellable away from the main actor; export completion does not change dirty baselines, default storage or Undo. Reference drafts retain imported snapshots through history. Shared Apply uses upstream exact revisions plus existing parent UUID guards. Only a recognized portable-capacity failure permits a clearly reported legacy-format fallback; other invalid or stale inputs preserve the parent.

WORLD-33 keeps the same document and interaction contracts while reducing large-map work. Native mesh and ghost buffers are prepared as immutable cancellable worker results; the main actor installs SceneKit objects. World placement changes reuse unchanged model geometry. Slice drawing clips to visible cells with a one-cell fringe, resolves each distinct visible glyph once per draw, and uses a detached thumbnail cache keyed by that slice and appearance. Metadata-only title edits and their Undo/Redo retain the existing mesh revision while remaining ordinary dirty document edits. Performance receipts distinguish preparation, installation, camera submission and synchronized snapshots from an on-screen frame-rate measurement.

The editor opens in Sculpt mode with a dominant translucent Cubes canvas, the hollow orb, and a compact slice strip. Cubes and ASCII present the same volume. With Paint off, drag orbits and click selects; with Paint on in Cubes, surface gestures add, erase, or fill. Slice mode shows the visual grid with Fit, 2×, 4×, 8×, and 16× zoom, contextual tools, a small 3D reference, and optional selected-cell keyboard controls. Cmd-1 and Cmd-2 switch modes. Cmd-K opens an accessible searchable command palette; arrow keys choose a result, Return runs that highlighted action, and Escape closes it and restores focus. The palette calls the same native save/open/export/dirty guards as visible controls. Scene document commands provide New empty sculpture (Cmd-N), Open sculpture (Cmd-O), Save compact 3md (Cmd-S), and Save readable 3md (Cmd-Shift-S) through the same guarded actions; they are disabled when the editor scene is not focused. The editor File menu also creates empty 16-, 32-, 64-, 128-, or 256-cubed volumes, opening Cubes with Paint enabled. It exposes no arbitrary execution or language interpreter. Camera framing fits once for a default camera and on explicit Fit; it does not reset on every edit.

Workspace rename, fill, clear, rotate, and structured transactions use `SculptureCommandEngine`. A successful batch is one undoable edit; a rejected batch leaves the document and undo stack unchanged. Direct brush drawing uses the same validated `Sculpture.paint` primitive with clipped brush geometry and coalesced stroke undo. UI cell labels are one-based; structured document coordinates are zero-based.

`RookApp` owns window id `main`, titled `Sculpt.3md`, Settings, and the menu bar extra `Sculpt.3md`. `CFBundleName` and `CFBundleDisplayName` are `Sculpt.3md`. `CFBundleExecutable` remains `Rook`. `CFBundleIdentifier` remains `labs.corvid.rook`. `RookDelegate` keeps the process alive after the last window closes and asks before quitting dirty work. `RookMenu` offers Show Sculpt.3md, Settings, and Quit Sculpt.3md. `MainView` hosts `SculptureEditor` with one `SculptureWorkspace`.

`SculptureWorkspace` holds the session sculpture, title draft, layer, cell, brush, tool, brush size, viewpoint, camera, render style, Paint mode, and cube opacity. Tools are Draw, Erase, and Fill. Viewpoints are Orbit, Front, Side, and Above. `paint(_:start:size:)` draws, erases, or flood-fills on the selected slice and records one undo step per stroke. Draw and erase interpolate same-slice drags and expand by the brush size. Fill replaces the connected cells of the same glyph on that slice. `paintVoxel(_:start:)` uses a ghost cell or empty face neighbor for Draw and the hit cube for Erase or Fill, with one-cell brush size. `change(_:)` applies a mutation and stores an error sentence. `undo()` and `redo()` restore sculpture snapshots. The camera and presentation are not undo values. `replace(with:opened:)` swaps the sculpture, changes its generation identity, clears undo, and resets the camera. `markSaved(_:)` records the snapshot written by a successful document save; prepared saves also require a matching document generation. `canUndo`, `canRedo`, and `isDirty` are derived; an uncommitted title draft is dirty. The workspace `frame` is the ASCII projection for text export.

GALLERY-41 makes `SculptureExamplesBrowser` one gallery of every `SculptureGalleryCatalog` entry: voxel models, compositions, worlds and the math ladder, grouped by kind and category with search, filters and each entry's size. Listing reads metadata only. Models up to 64 cells per axis render thumbnails automatically in detached work; larger entries render a bounded preview only after Load preview. Opening an entry generates and prepares it in a detached task with a stage, progress and Cancel, then routes it to the main, composition or world editor; Cancel publishes nothing. The final Grand solar system is an editable 256-cubed Space scene with artistically compressed planet sizes and distances. Choosing one asks before a dirty replacement, then loads that volume. Maps, Worlds, and Space set camera pitch to 0.7; other examples use 0.35. Gallery thumbnails of compositions and worlds also use pitch 0.7. Thumbnails use zoom 0.9 for Space, keeping the comet tail in frame, 1.3 for other authored models, and 1 for math ladder models, compositions and worlds. `SculptureExportStudio` captures the sculpture, camera, style, and cube opacity when opened and exports a GIF, an MP4, or an OBJ from that snapshot. It shows progress, can be cancelled, and then presents one `FileDocument` `fileExporter` inside the studio. It does not use `fileMover`. Cancel leaves the open sculpture in place.

The slice list creates rows lazily while preserving stable slice identifiers. It centers selection on appear, on a depth change, and on a layer change except when clicking a visible sidebar slice. That click selects the slice without recentering the list under the pointer; canvas and keyboard selection still reveal their slice. Three-digit selected slice numbers stay on one line beside the checkmark.

`SculptureViewport` prepares immutable camera-independent cube scenes away from the main actor and reuses their GPU buffers for camera changes. `SculptureWorkspace.sculptureRevision` changes only when voxel dimensions or layer bytes change, including changes caused by Undo, Redo or replacement. Metadata-only title edits and their Undo/Redo retain that revision while preserving ordinary dirty/save/Undo semantics; camera, slice, Paint mode and opacity also leave it unchanged. Replacement changes the document generation independently of geometry cache reuse. Obsolete or canceled extraction cannot replace the current scene. Selection requires the installed revision and camera to match. A painting stroke freezes the matched scene, camera, selected slice, ghosts and document generation, preventing added cubes from changing subsequent hits. Rebuilding is deferred until that stroke ends. ASCII and the non-Metal fallback still publish each completed bitmap with its matching projection in detached work. Replacement, presentation changes, and gesture completion end the stroke.

`SculptureCanvasPointer` is a native canvas-local NSView bridge above the embedded GPU view or bitmap fallback. It delivers mouse down, drag, and up in flipped local coordinates, scoped to its view and window. It uses no global event monitor. Mouse down acquires the existing native canvas keyboard target before starting a paint or orbit gesture. `SculptureViewport` routes those phases to frozen-scene painting and camera callbacks; a click below the drag threshold selects, and an Orbit drag moves the camera. Native pointer delivery and live validation are tracked separately.

`LayerGrid` is the drag grid for one Z slice. Fit, 2×, 4×, 8×, and 16× zoom use canvas-local geometry in a two-axis scroll view, with dimensions bounded by `Sculpture.maximumDimension`. Zoom changes center the selected cell and finish a stroke; keyboard selection centers it while zoomed. `SculptureFile` can read and write codec bytes. Production compact/readable Save, PNG export, and ASCII text export share one `fileExporter` in the main editor. PNG uses the current render style and cube opacity, while text remains ASCII. Its document is `SculptureExport`, with content type `.compactSculpture`, `.sculpture`, `.png`, or `.plainText`. The studio uses a second `fileExporter` on its own view, with content type `.gif`, `.mpeg4Movie`, or `.sculptureMesh`. Each view has one `fileExporter`. `UTType.sculpture` is `labs.corvid.rook.sculpture`, conforming to plain text with extension `.3md`. `UTType.compactSculpture` is `labs.corvid.rook.compact-sculpture`, conforming to data with extension `.3mdb`. `UTType.sculptureMesh` is the `obj` extension, or `.data` when that type is unavailable. `Brand` holds the CorvidLabs palette, and the studio applies it.

`SculpturePreparedSave` carries a request id, document generation, snapshot, storage format, and data. `SculptureSaveJob` owns background preparation and exposes only current completion, running state, and error to the editor. It starts no process and writes no file itself.

## Behavioral Examples

- Closing the main window and choosing Show Sculpt.3md orders that same window forward.
- Settings offers system, light, and dark, and the stored value is `rook.appearance`.
- A paint stroke of two cells undoes and redoes as one sculpture change.
- Save 3md writes the codec bytes. Reopen restores that sculpture and a fresh camera.
- Export Image writes a PNG in the current Cubes or ASCII style and cube opacity. Export ASCII text writes `frame.text` regardless of display style.
- A document that `SculptureCodec.decode` rejects shows the error and keeps the sculpture already in the window.
- Choosing a dirty example asks before replacement. Cancel leaves the current sculpture. A Maps, Worlds, or Space example then uses pitch 0.7.
- Cancelling a GIF, MP4, or OBJ export leaves the open sculpture and its undo stack unchanged. The studio save step uses one `FileDocument` `fileExporter`. A failed save keeps the generated file.
- Opening a new 256-cubed volume starts Cubes Paint mode with a pickable selected empty slice. One surface stroke undoes in one step without moving the camera.
- A zoomed 256-cell slice can be scrolled and edited using canvas-local coordinates, and keyboard selection stays visible.

## Error Cases

There is no launcher flag. Quit with unsaved changes asks to cancel or discard. Replacing a dirty sculpture asks to discard or cancel. Decode, panel, and PNG failures set `SculptureWorkspace.error` to the error's localized description. An invalid title does not replace the previous title. PNG failure tells the person to try ASCII text. The app does not convert an unsupported schema. A cancelled animation or mesh export sets the studio error to `Export cancelled.` and deletes its temporary folder. A failed export or save sets the studio error to the error's localized description and keeps the generated file for another save attempt.

Selected-file/folder insertion identifies a refused source by filename; tile-fit errors name the source file (or the model title for an insertion without a file) with required and current dimensions. Select changes the insertion start without painting or history. Prepared occupied-cell replacements require explicit confirmation and retain captured parent/snapshot/selection guards. Cancel or a stale candidate leaves scene, portable metadata and Undo unchanged. Publication and world handoff are unavailable during preparation or confirmation. When the portable limit refuses and neither the scene nor any input carries portable data, insertion uses native values and shows a notice; otherwise it names the portable limit and the affected files and inserts nothing. Native saves and insertions that could not reopen within the 100,000-line or 20 MiB decode budget are refused before writing.

COMPOSITION-39 makes insertion discoverable. While a composition or world sheet is idle, the File menu offers Insert 3md… (Shift-Command-I) and Insert model folder… (Option-Shift-Command-I), presenting the same importer and rules as the sheet buttons. The command palette offers Insert 3md and Insert a model folder into a new composition (a blank 4 by 4 by 4 grid of 64-cell tiles) or a new world, which open the canvas and present its importer; these entries are unavailable while a sheet, save, export or open is in progress, like New and Open. Menu Undo and Redo act on the open composition, world or shared-model history, track that history as it changes, and are unavailable for other sheets and while a shared edit is applying, so the hidden main sculpture never changes. A shared-model Apply refuses to publish if its model changed during validation. Same-title, same-size models in the Edit shared model menu add their bound glyph or first placement. Batches use natural filename order. A successful insertion announces its first and last tiles and whether it continued onto the next row or another layer. Example replacement clears stale portable data, Use in a world carries the composition's portable data captured off the main actor, Edit shared model menus, library rows and world instance labels show model titles and dimensions rather than generated IDs, and inserting, placing or moving at an unchanged Explore focus keeps the eye position.
